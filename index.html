Field Notes & Learnings

TIL (Today I Learned)

Updated for macOS Sonoma & Sequoia
macOS Declarative Device Management (DDM) Update Enforcements ↓

Declarative Device Management (DDM) allows macOS devices to autonomously process state logic without waiting for server polling cycles. When implementing software update declarations, ensure target Macs possess a valid bootstrap token escrowed in Jamf Pro.

Zsh / API OAuth Bearer Token Caching for Jamf Pro Classic & Pro APIs ↓

Repeatedly requesting OAuth tokens on every script invocation can trigger rate limiting on Jamf Pro Cloud instances. Cache the bearer token with an expiration timestamp check to optimize script throughput across large fleet automated tasks.

ASM Apple School Manager Class Sync & Token Lifecycle ↓

If rostered classes fail to populate in Apple Classroom, verify Managed Apple ID status and token trust relationships between ASM and Jamf School/Pro. Schedule token renewals 30 days prior to annual expiration.
